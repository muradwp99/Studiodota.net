# Super-Product Feature Catalog — Studiodota CMS

> The full "what could this become" list, to make the admin a flexible, sellable
> product. Grouped by domain. Tiers: **[now]** = v1.0 in progress · **[next]** =
> v1.5 · **[later]** = v2.0+ · **[opt]** = per-client add-on/plugin.
> ★ = explicitly requested by the owner.

## 1. Visual editing (the flagship — "live preview editor" ★)
- ★ **True inline/live editing** — click text on the canvas and type; edit images in place. [next]
- ★ **Live preview** split view + **device preview** (desktop/tablet/mobile) + light/dark preview. [next]
- **Drag-and-drop** block reordering (grip handles), drag from an inserter panel. [next]
- **Layout blocks:** columns, grid, container/section, spacer, tabs, accordion, cards. [next]
- **Global / reusable blocks** (edit once → updates everywhere). [next]
- **Block patterns / section library** (pre-designed hero, pricing, team, CTA…). [next]
- **Undo/redo history**, copy/paste blocks across pages, duplicate, keyboard shortcuts. [next]
- **Per-block style controls** (spacing, background, alignment, radius, shadow — within brand tokens). [next]
- **Responsive controls** — hide block on mobile/desktop, per-breakpoint settings. [next]
- **Starter templates** for a new page (pick a layout instead of blank). [next]
- Right-click context menu, block search, block locking. [later]

## 2. Content types & flexibility (config-driven)
- ★ **Custom content types** per client (Properties, Team, Events, Services, Products, Testimonials…) declared in config, no code. [next]
- **Custom fields** (text, rich text, number, date, select, toggle, color, relation, repeater, file). [next]
- **Taxonomies** — categories, tags, custom taxonomies, hierarchical. [next]
- **Relationships** between content (link a post to a project, a project to a team member). [next]
- **Scheduling** (publish at date/time), **expiry**, **draft/review/published** workflow. [next]
- **Full revision history** + diff + one-click restore. [next]
- **Duplicate/clone** content; **bulk actions** + bulk edit; **import/export** (CSV/JSON, WordPress import). [next]

## 3. SEO ★
- ★ Per-page **SEO title, meta description, focus keyword** + **Google/social snippet preview**. [now/next]
- ★ **Open Graph + Twitter Card** fields + per-page share image. [next]
- **Canonical URL, noindex/nofollow, sitemap priority** per page. [next]
- **Auto `sitemap.xml` + `robots.txt`** (editable). [next]
- **Schema.org / JSON-LD** (Organization, LocalBusiness, Article, Product, FAQ, Breadcrumb, Review). [next]
- **Redirect manager** (301/302) + **404 monitor**, broken-link checker. [next]
- **SEO analysis score** (Yoast-style: readability, keyword, links, alt-text checklist). [later]
- Breadcrumbs, hreflang (i18n), RSS feed.

## 4. Marketing, tracking & code injection ★
- ★ **Meta (Facebook) Pixel, Google Analytics 4, Google Tag Manager, TikTok/LinkedIn/Pinterest tags** — paste an ID, done. [now — quick win]
- ★ **Custom code injection** — header / body / footer scripts, **per-site and per-page**; custom `<meta>` tags. [now — quick win]
- **Cookie consent / GDPR banner** + Google Consent Mode. [next]
- **Email marketing** integrations (Mailchimp, Brevo, ConvertKit, Resend) + newsletter signup + list sync. [opt]
- **Form builder** — drag fields, multi-step, conditional logic, file uploads, **email notifications + autoresponder**, spam protection (Turnstile/reCAPTCHA/honeypot), submissions inbox + CSV export. [now→next]
- **CRM / automation** — Zapier, Make, generic **webhooks** on events. [opt]
- **Live chat** (WhatsApp ✓; add Messenger, Crisp, Intercom, Tawk). [opt]
- **Booking/scheduling** (Calendly, Cal.com embed). [opt]
- **A/B testing / experiments**, UTM builder, **heatmaps** (Hotjar/MS Clarity) injection. [later]

## Suggested priority (highest value-per-effort first)
1. **Quick wins that read as "flexible & pro" immediately:** custom code injection (header/footer), analytics + Meta Pixel IDs, per-page SEO + OG + sitemap/robots, enquiry email notifications. (Days, not weeks.)
2. **The flagship:** live/inline preview editor + drag-drop + more blocks (columns, patterns, reusable blocks). This is what makes "create a page" feel effortless.
3. **Safety net** (autosave, unsaved-guard, draft preview, revisions) — in progress; Trash ✓.
4. **Media upgrade** (search, alt, drag-drop, optimize).
5. **Config-driven content types** — the real "reuse per client, any structure" unlock.
6. **White-label + theme customizer + roles** — productization for selling.
7. Everything else per demand / per client (commerce, i18n, AI…).
